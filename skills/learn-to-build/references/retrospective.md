# Retrospective

Closes the Core path: a whole-codebase review that compares the Learner's design with the real X and turns the Project into lasting lessons. Reached from `next`.

## 1. Review the whole codebase

**dispatch** a reviewer with [reviewer-brief.md](reviewer-brief.md) in Retrospective mode, with the inputs it lists.

**Done when** the report has every part the brief lists.

## 2. Record and schedule

Write the report to `.ltb/log/retrospective.md`. For each Drill it proposes, run `./ltb drill add --concept <concept> --stage <latest Stage it spans> --paths <paths>`. Add `Retrospective: done <date>` under the plan's Core path table. **commit Harness** with `ltb: retrospective`.

**Done when** the commit exists.

## 3. Present

Walk the Learner through the architecture comparison, the Defences revisited, the three lessons, and what assistance cost or saved. Then offer any remaining Branches through `next`.

**Done when** the Learner has seen the three lessons.
